# Espectro Cinza — Landing Page

Landing page estática, responsiva e pronta para abrir localmente ou publicar em hospedagem estática.

## Estrutura
- `index.html` — estrutura da página
- `styles.css` — identidade visual, responsividade e animações
- `script.js` — menu, carrossel, reveal, cursor glow e configuração de links
- `assets/` — imagens fornecidas pelo usuário

## Links editáveis
Abra `script.js` e altere:
- `LINKS.courses` para as páginas oficiais dos cursos na Hotmart.
- `LINKS.social` para Discord, X, YouTube e Instagram.

## Observações
- As imagens do usuário foram mantidas como arquivos próprios dentro de `assets/`.
- O hero usa a imagem de galeria em preto e branco.
- O CTA usa o retrato de cabelo vermelho com tratamento monocromático.
- O carrossel usa cinco imagens enviadas pelo usuário, sem geração ou substituição por banco de imagens.
- O site usa Font Awesome via CDN para os ícones sociais. Para publicação 100% offline, substitua o CDN por uma cópia local da biblioteca.
